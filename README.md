# Nara & Arga — Wedding Invitation

Static wedding invitation website, ready for GitHub Pages.

## Customize

Edit the names, date, venue, family details, bank details, and links in `index.html`. Update the countdown date in `script.js`.

Personalize the guest name with a URL parameter:

`https://your-name.github.io/repository/?to=Bapak%20Budi`

## Publish with GitHub Pages

Push these files to a public GitHub repository. In **Settings → Pages**, choose **Deploy from a branch**, then select `main` and `/ (root)`.

Note: The sample RSVP form stores responses only in the visitor's browser. Connect Formspree, Google Forms, or a backend before collecting real responses.
